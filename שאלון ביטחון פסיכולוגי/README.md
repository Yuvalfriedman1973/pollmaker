## נקודות פתוחות

- ה-PDF `Psychological-safety.pdf` (avneyrosha.org.il) לא היה נגיש בזמן הבנייה. ההסבר התיאורטי נכתב מהידע הכללי ולא ממנו, וכדאי להשוות את הממדים מולו.
- השאלון אינו מתוקף פסיכומטרית ואינו השאלון המקורי של אדמונדסון (7 פריטים). הוצעה אפשרות להוסיף את שבעת הפריטים המקוריים כחלק נפרד, אך לא בוצעה.
- הגרסה לחברי צוות/קבוצה קיימת כתבנית בדף הניהול, אך אינה הגרסה הפעילה.
